How it works

Trigger in. Result out.

  1. Trigger

    A form, a payment, a call, an e-mail, a schedule.

  2. Route

    Validate, deduplicate, decide which path to take.

  3. AI step

    Claude reads, classifies, writes and extracts.

  4. Actions

    CRM, calendar, invoices, e-mail, WhatsApp, sheets.

  5. Log & retry

    Every run recorded; errors retried, then reported.
